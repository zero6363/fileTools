## 更新记录

### 2026-10-26

- ⑲ 修复 + 校验哈希逻辑完善：
  - **修复「重新计算哈希不写库」**：内部把选中行转成任务参数时多带了一个字段，
    重算任务一启动就崩掉，一条都没写进去；现在多选 / 单选右键「重新计算哈希」
    算完都会真正写库（快建档的「未计算」记录也能直接补上）。
  - **差异行也能校验哈希**：快速预检 / 快速建档扫出的「变更 / 新增 / 缺失」清单，
    右键「校验哈希」直接用——「变更」的行会现算当前哈希和**库里的旧哈希**比：
    一致说明内容没变（只是日期动了），不一致就是真改了；「新增」的行标「库里没有」。
  - 校验结果窗加**修改时间列**：内容一致但日期和库对不上的行标橙色，
    可勾选后**统一修改时间**——「用新时间」= 把库的日期更新为文件当前日期（不改文件），
    「用旧时间」= 把文件的日期改回库里的记录（不改库），统一后预检不再报「更新」。
  - 结果窗「写入数据库」升级：对「已变化 / 无库内哈希」的行把**哈希、大小、修改时间**
    一起按磁盘当前值写回（之前只写哈希，日期对不上会一直报差异），写回后预检干净。
  本次版本号 **v1.31**。

- ⑲ 「检查不重复」新增**按哈希比对**模式（窗口顶部可切换）：
  - **按路径比对（镜像）**：默认，按相对路径对齐，适合镜像盘校验。
  - **按哈希比对（找改名 / 移动）**：按 SHA256 配对两边的文件——改名、移动、
    换文件夹都能配上对，标「内容一致」并在右栏显示改名后的名字；
    只在一边出现的照旧标复制箭头。只比较库里**已算过哈希**的记录，
    汇总栏会提示两边各有几条「未算哈希」（先补全哈希再比更全）。
  - 右键同步在哈希模式下同样可用：配对成功（内容一致）的对只同步修改日期
    （不会重复复制字节），复制的目标路径用改名后的新名字。
  - 导出 CSV 增加「右相对路径」列。
  本次版本号 **v1.30**。

- ⑲ 「检查不重复」的**目录节点也按侧显示**：某个文件夹只在一边有文件时，
  另一边的该目录显示为空（占位行保留、行对齐不变），不再两边都画出目录名。
  本次版本号 **v1.29**。

- ⑲ 「检查不重复」再优化：
  - **单边文件的缺失一侧显示为空**（之前画「—」占位）：只在左边 = 左栏有文件、右栏整行空白。
  - 左右栏加**修改时间列**，直观看出哪边更新。
  - **区分「更新」和「复制」两种箭头**：单边文件是复制（→ 只在左边 / ← 只在右边），
    两边都有但内容不同的按修改时间标**更新箭头**（⇥ 左侧有更新 = 用左覆盖右 /
    ⇤ 右侧有更新 = 用右覆盖左），修改时间分不出方向的保留「内容不同（≠）」。
  - 底部分类同步拆分：全部 / **左侧有更新** / **右侧有更新** / 内容不同（方向不明）/
