# 文件工具箱 · 多功能合集

Windows 上的图形化批量文件处理合集：把 19 个常用小工具塞进同一个窗口，左侧纵向菜单切换即可使用。全部操作都在本地完成，不联网、不上传任何文件。

> **设计原则：只做整理，不做破坏。** 所有移动 / 重命名 / 覆盖类操作都带防覆盖策略（同名跳过或自动改名、两阶段重命名、先预览后执行），宁可跳过也绝不误删、误覆盖。

## 功能一览

| 编号 | 功能 | 做什么 |
| :--: | --- | --- |
| ① | 文件分组 | 按数量（每组 N 个）或按年月把文件分到子文件夹 |
| ② | 移动到根目录 | 把所有子目录里的文件提升到根目录 |
| ③ | 删除空文件夹 | 循环清理嵌套的空目录 |
| ④ | 实况图分组 | 识别安卓实况图（JPEG 内嵌视频），分出实况图 / 静态图，可提取 mp4 |
| ⑤ | 文件名添加路径 | 把目录层级写进文件名（`根目录-子目录-原名`） |
| ⑥ | 序号重命名 | 批量改成 `001/002…` 或 `001-原名`，支持拖放、自然排序 |
| ⑦ | 视频常用压制 | FFmpeg 批量压制：AV1 / H.265 自由选，硬件编码器自动选择，内嵌字幕硬烧，源文件自动归档 |
| ⑧ | 视频横竖屏 | 读视频头判断横屏 / 竖屏并分文件夹，速度极快 |
| ⑨ | 文件名删除 | 按位置删除文件名中的字符（从前 / 从后、第几位、删几个） |
| ⑩ | 图片生成MD | 把图片整理成 Markdown（复制图片 + 生成索引），支持增量更新 |
| ⑪ | TXT转图片 | 把 TXT 批量渲染成 PNG（中文自动换行） |
| ⑫ | TXT合并 | 按后缀把多个文件合并成一个，保留来源标注 |
| ⑬ | TXT重命名 | 用 TXT 第一行的文字作为文件名 |
| ⑭ | WebP转JPG | WebP 批量转 JPEG，可转完删除原文件 |
| ⑮ | 加密包分类 | 扫描压缩包，把加密的挑出来移到指定文件夹 |
| ⑯ | 图片压缩 | mozjpeg Huffman 无损优化 / libjpeg-turbo 重压缩，看体积省多少 |
| ⑰ | ReSoBackup备份 | Reed-Solomon 纠删码分片备份，任意 K 份即可恢复，可选 AES-256-GCM |
| ⑱ | 文本翻译 | 批量翻译 txt / lrc / srt / ass / vtt 等文本成中文，保留时间轴，免费接口自动切换 |
| ⑲ | 硬盘哈希扫描 | 冷数据建档 + 增量校验：四种模式（快速预检 / 快速建档 / 完整检查 / 完整建档），差异跨页多选写回、列表分页 + 复选框、多目录统一管理 / 跨库检索、查重复文件、两目录 FreeFileSync 式左右双栏比对、子库合并 / 用上级库、右键只读校验哈希 |

## 环境要求

- **系统**：Windows 10 / 11（64 位）。
- **直接跑 exe**：无需安装，双击 `文件工具箱.exe` 即可。
- **从源码跑**：Python **3.10 及以上**且带 `tkinter`（建议官方安装包并勾选 `tcl/tk and IDLE`；精简版 Python 常缺 tkinter 导致启动即退出）。
- **第三方依赖**（按需，见 [依赖与降级策略](#依赖与降级策略)）：
  ```bat
  pip install pillow chardet pycryptodome pyzipper rarfile py7zr
  ```
- **FFmpeg（仅 ⑦ 需要）**：外部程序，不内置。没装只影响 ⑦，其它 18 个工具照常使用。

## 快速开始

### 方式一：使用打包好的 exe（推荐）

1. 双击 `文件工具箱.exe`（单文件、无控制台窗口）。
2. 左侧点选功能，填好参数，点右下角按钮执行。
3. 窗口大小 / 位置 / 菜单栏宽度自动记住，存于 exe 同目录的 `toolbox_config.json`。

> 首次启动单文件 exe 需解压到临时目录，可能等几秒；杀毒软件偶尔会误报（PyInstaller 单文件包行为特征类似"自解压程序"），源码就在仓库里可自行打包。

### 方式二：从源码运行

```bat
:: 双击 启动工具箱.bat，或：
python 文件工具箱.py
```

`启动工具箱.bat` 优先找带 tkinter 的 `pythonw.exe`（无控制台），找不到时回退命令行 `python` 并显示报错。

## 界面与操作约定

- **左侧纵向菜单**：19 个功能分组排列；高度不够时滚轮滚动。
- **菜单栏宽度可调**：拖右侧分隔条调整，双击恢复默认（250px，范围 240–380px），宽度自动记住。
- **参数区**：路径行带"浏览…"，后缀 / 格式行支持直接输入自定义值（如 `.webp .heic`、`jpg png`）。
- **日志区**：多数操作逐条记录，执行中按钮禁用避免重复点击；⑦⑲ 等页面日志可展开 / 收起。
- **先预览后执行**：⑤⑥⑨ 重命名类先"预览结果"，确认无误再执行。
- **拖放**：⑥⑦⑧⑨⑯⑰ 等支持把文件 / 文件夹直接拖进列表（自实现 Windows 拖放，基于 `ctypes` + `SetWindowSubclass`，不依赖第三方库，无 64 位回调截断崩溃）。

## 数据安全设计

| 场景 | 策略 |
| --- | --- |
| 分组 / 移动时目标已存在同名文件 | 跳过，或（可选）自动改名，**绝不覆盖** |
| 重命名（⑤⑥⑨） | 两阶段重命名，先临时名后目标名；执行前必须预览 |
| 复制图片到 `appdata/Image` | 文件名带 6 位随机串，拷贝前检查是否已存在 |
| 生成 md / 合并 txt | 已存在时自动加 `_1`、`_2` |
| 生成 md（更新模式） | 只插入新增块，已有行原样保留；无新增时文件不改动 |
| 超长路径（> 255 字符） | 跳过并单独列出，不冒险写入 |
| 只读 / 动图 | 压缩时跳过并记录原因 |
| 覆盖原图（⑯） | 页面明确标注"不可逆，请先备份"；不想覆盖可改用「原路径重命名」或「保存到指定路径」 |
| 压制输出（⑦） | 输出名带 `crf` 质量值，同名自动加序号；源文件只在成功后移入 `success/`，失败移入 `error/` |

## 打包成 exe

双击 `打包.bat`，或手动执行：

```bat
python -m PyInstaller --onefile --windowed --noconfirm --clean ^
    --name 文件工具箱 ^
    --add-data "bin\mozjpeg;bin/mozjpeg" ^
    --hidden-import PIL.Image --hidden-import PIL.ImageDraw --hidden-import PIL.ImageFont ^
    --hidden-import Crypto.Cipher.AES --hidden-import Crypto.Util._raw_api ^
    文件工具箱.py
```

- `--onefile --windowed`：单文件、不带控制台窗口。
- `--add-data bin\mozjpeg`：把 mozjpeg 一起打包（缺失时 ⑯ 自动回退 `libjpeg-turbo`）。
- `--hidden-import`：Pillow / PyCryptodome 部分子模块动态导入，不声明会被裁掉。
- **FFmpeg 不内置**：体积大且需匹配显卡驱动，放 exe 同目录（或 `bin\ffmpeg\`）即可。

## 常见问题

**Q：双击 `启动工具箱.bat` 闪退 / 无窗口？** A：多半是 Python 没带 tkinter，用命令行 `python 文件工具箱.py` 看报错；装 python.org 官方版并勾选 `tcl/tk and IDLE`。

**Q：拖文件进列表没反应？** A：确认程序不是"以管理员身份运行"——UIPI 限制下普通资源管理器无法向管理员窗口拖放，用「添加文件 / 添加文件夹」按钮。

**Q：图片压缩提示 mozjpeg 缺失？** A：`bin/mozjpeg` 没放到程序目录；自动回退 `libjpeg-turbo`，功能不受影响，只是压缩率略低。

**Q：`toolbox_config.json` 是什么？** A：唯一配置文件（窗口状态、压缩选项、ffmpeg 路径、已管理目录都在里面）。随意删除会恢复默认；只删某分区则该功能回默认。

**Q：覆盖原图后能撤销吗？** A：不能。⑯「覆盖原图」不可逆，页面有提示；批量前建议先备份或先用「保存到指定路径」。

**Q：⑦ 提示"未找到 FFmpeg"？** A：把 `ffmpeg.exe`、`ffprobe.exe` 放程序目录（或 `程序目录\bin\ffmpeg\`），或加进 PATH，或本页「浏览…」手动选中。

**Q：⑦ 显示"AV1 → 软件（libsvtav1）"，没开硬件加速？** A：显卡不支持 AV1 硬件编码（GTX 16 系、RTX 20 系、多数 Intel 核显都不支持）。程序会自动把编码格式切到 H.265 避免误用 CPU 慢压；想用 AV1 软件编码（体积更小）手动切回。

**Q：⑦ 整批报 `No such file or directory`？** A：一般是上次压制已把源文件归档进 `success/`，又用同一列表点了第二次「开始」。新版本每批结束自动移除已归档条目、开始前再校验，正常不会再出现。

## ⑲ 硬盘哈希扫描（要点）

冷数据「建档 + 定期校验」工具，回答两个问题：**这块盘上的文件还是原来那个吗？哪些文件不见了？**

- **四种模式**（「改不改库 × 算不算哈希」组合）：

  | 模式 | 改库 | 算哈希 | 适合场景 |
  | --- | --- | --- | --- |
  | **快速预检**（默认） | 不改 | 不算 | 日常巡检：只比大小 + 时间，不读文件不写库 |
  | **快速建档** | 改 | 不算 | 先摸清家底：只记路径 + 大小 + 修改时间 |
  | **完整检查** | 不改 | 算 | 算出新哈希但不写库，把差异摆出来逐条确认 |
  | **完整建档** | 改 | 算 | 正式建档 / 复核：算 SHA256，补上快速建档的空哈希，标记缺失 |

- **差异写回**：预检 / 检查的差异清单（新增 / 更新 / 删除）支持跨页多选（行首复选框 + Ctrl/Shift + 全选本页/全部），只写回勾选行；不算哈希的模式写回时清空旧哈希。
- **列表分页**：默认 500 条/页（100–5000 或全量可选），勾选跨页保留；导出 CSV 按当前筛选全部记录。
- **一库一根**：`filehash.db` 直接建在扫描根目录；库自身产生的文件永不录入。
- **跨库管理**：多目录统一管理（勾选列、最后扫描相对时间、扫描记录），跨库检索；多选目录查重复文件；两目录 FreeFileSync 式左右双栏比对（分类筛选可显示/隐藏相同文件）。
- **子库合并 / 用上级库**：可把子目录 `filehash.db` 合并进当前库，或反过来用上级库给子目录建库；全程只动数据库不读普通文件。
- **右键校验 / 重算哈希**：校验只读比对新算 SHA256（不写库），结果可勾选写回；重算立即写库。
